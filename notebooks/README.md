# Original experiment

`original_experiment.ipynb` is the original Colab notebook, preserved with its outputs for project history. It used Google Drive paths, TensorFlow/Keras imports from its original environment, no held-out split, and training-accuracy-based stopping.

Its 88.16% result is **training accuracy**. The sample prediction uses an image from the training collection. The notebook is not the supported training entry point and is excluded from lint/format checks.

Use the packaged CLI described in the root README for new experiments. The notebook has been renamed from `cat_breeed_detection.ipynb`; any old external Colab link may need to be updated to this location. Its original content is intentionally retained.
